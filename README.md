# 👋 Hi, I'm Josue Elizalde

## 🔬 Projects in Machine Learning, Neuroimaging, Data Analysis and High Energy Physics

#### Selected Projects
#### [Bird Song Classification](https://github.com/GalloElizalde/bird-audio-classifier)
Developed a transfer learning pipeline based on convolutional neural networks (CNNs) for multilabel bird species classification from environmental audio recordings. The project included preprocessing methods based on mel-spectrogram and Wigner time-frequency representations, audio augmentation techniques to improve robustness under noisy real-world conditions, and ensemble/postprocessing strategies to improve classification performance on BirdCLEF soundscape data.


#### [Brain Age Prediction from MRI](https://github.com/GalloElizalde/BrainAge-CNN)  
Developed a CNN-based regression pipeline to predict patient age from brain MRI scans. The project preprocesses 3D MRI volumes by extracting central axial slices, normalizing each subject, and stacking slices as input channels, then evaluates how different numbers of slices affect age prediction performance using metrics such as MAE, RMSE, bias, Pearson correlation, and R².


#### [fNIRS PCA–ICA Finger Tapping Analysis](https://github.com/GalloElizalde/fnirs-pca-ica-finger-tapping)  

Developed an fNIRS analysis pipeline for finger-tapping experiments using oxy- and deoxy-hemoglobin signals. The project applies band-pass filtering and compares PCA with FastICA to decompose hemodynamic recordings into latent components, identify task-correlated and noise-dominated components, and evaluate both methods using reconstruction error and component-task correlation across multiple subjects.


#### [Breast Cancer Clustering Analysis](https://github.com/GalloElizalde/data-mining-breast-cancer)  

This project explores clustering as a representation problem, analyzing how preprocessing pipelines and dimensionality reduction strategies reshape the data manifold and influence downstream interpretability, rather than optimizing for a single clustering score.


#### [Spin Correlations in $t\bar{t}$ Production (SMEFT)](https://github.com/GalloElizalde/spin-correlations-smeft)  

This work studies spin correlations in top-quark pair production as a bridge between data-driven analysis and effective field theory, focusing on interpreting statistical observables in terms of SMEFT operators rather than replacing theory with machine learning.
